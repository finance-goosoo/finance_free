# 나의 가계부 (finance_free)

가입 없이 바로 쓰는 PC용 개인 가계부예요.

👉 **https://finance-goosoo.github.io/finance_free/**

- 수입·지출 항목을 내 방식대로 정해서 기록
- 홈에서 월별/연간 손익과 카테고리 비중(도넛 그래프) 확인
- 자산(예적금·투자) 월별 잔액 기록과 추이 그래프

## 데이터는 어디에 저장되나요?

모든 데이터는 **사용하는 컴퓨터의 브라우저 안에만** 저장되고, 어떤 서버로도 전송되지 않아요.
다른 기기나 다른 브라우저와는 연동되지 않으니 **한 컴퓨터의 한 브라우저(크롬·엣지 권장)**에서 써주세요.
브라우저 기록을 지우면 사라질 수 있으니 **설정(⚙) → 백업 파일 내보내기**로 가끔 백업해두세요.
