# 나의 가계부 (finance_free)

가입 없이 바로 쓰는 개인 가계부예요.

👉 **https://jinns89.github.io/finance_free/**

- 수입·지출 항목을 내 방식대로 정해서 기록
- 홈에서 월별/연간 손익과 카테고리 비중(도넛 그래프) 확인
- 자산(예적금·투자) 월별 잔액 기록과 추이 그래프

## 데이터는 어디에 저장되나요?

모든 데이터는 **사용하는 기기의 브라우저 안에만** 저장되고, 어떤 서버로도 전송되지 않아요.
그래서 폰을 바꾸거나 브라우저 데이터를 지우면 사라질 수 있어요.
**설정(⚙) → 백업 파일 내보내기**로 가끔 백업해두세요.

## 홈 화면에 설치하기

- 아이폰: Safari 공유 버튼 → 홈 화면에 추가
- 안드로이드: Chrome ⋮ 메뉴 → 홈 화면에 추가
