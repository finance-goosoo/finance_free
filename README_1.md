# 나의 가계부 (finance_free)

가입 없이 바로 쓰는 개인 가계부예요.

👉 **https://finance-goosoo.github.io/finance_free/**

- 수입·지출 항목을 내 방식대로 정해서 기록
- 홈에서 월별/연간 손익과 카테고리 비중(도넛 그래프) 확인
- 지출·수입의 월별 추이 꺾은선 그래프
- 자산(예적금·투자) 월별 잔액 기록과 추이 그래프

## 꼭 알아두세요: 처음 설정한 기기 한 대에서만 쓸 수 있어요

모든 데이터는 **처음 설정한 기기(PC 또는 폰) 안에만** 저장되고, 어떤 서버로도 전송되지 않아요.
그래서 나만 볼 수 있는 대신, **다른 기기나 다른 사람과는 연동되지 않아요.** (PC↔폰 동시 사용, 부부 공유 불가)

- **PC**: 크롬 또는 엣지 권장
- **안드로이드**: 크롬 권장
- **아이폰**: Safari 공유 버튼 → **홈 화면에 추가**한 뒤, 홈 화면 아이콘으로 열어서 시작하세요.
  (Safari에서 바로 쓰면 7일간 접속하지 않을 때 데이터가 지워질 수 있고, 홈 화면 앱과 데이터가 따로 저장돼요)

기기를 바꿀 땐 **설정(⚙) → 백업 파일 내보내기** → 새 기기에서 **불러오기**로 옮길 수 있어요.
